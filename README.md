# Fynd Studio Command Centre

Internal operations platform for Fynd Studio — a design and AI-generated media agency.

**Live:** [studio.fynd.design](https://studio.fynd.design)

## Stack

Next.js 15 (App Router) / React 19 / Tailwind CSS / shadcn/ui / Supabase / Clerk / Vercel

## Quick Start

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # Production build
npm run lint       # ESLint
```
